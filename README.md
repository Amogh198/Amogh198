## `ls ./featured-projects`

### 1. TrustFeed — AI-Powered Content Analysis

[![TrustFeed](https://img.shields.io/badge/Explore-TrustFeed-00C2FF?style=for-the-badge&logo=github)](https://github.com/Amogh198/TrustFeed)

An AI-powered platform that analyses images, videos, text and links to identify potential manipulated media, misleading content and coordinated spread.

- Media authenticity signals and provenance analysis.
- Public platform monitoring and network analysis.
- Evidence-based risk summaries and explanations.

**Focus:** AI · Media Forensics · Python · React

### 2. MoneyMal — Financial Crime Detection

[![MoneyMal](https://img.shields.io/badge/Explore-MoneyMal-00C2FF?style=for-the-badge&logo=github)](https://github.com/Amogh198/Money-Mal)

A graph-based financial forensics platform designed to identify suspicious transaction patterns and potential money muling networks.

- Circular transaction and shell-account detection.
- Smurfing, layering and velocity-burst detection.
- Batch transaction analysis and real-time profiling.
- Graph-based investigation dashboards.

**Focus:** Python · FastAPI · React · Graph Theory · Machine Learning
